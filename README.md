# Chickinfry Go

The Go client runtime for Chickinfry. Go SDKs generated by the Chickinfry CLI
(`chik generate`) import this module; most applications use the generated client
rather than calling this package directly.

**Status: in development.** Go is not marked as a supported language until
verification is complete.

## Requirements

Go 1.26 or later (`go.mod` declares `go 1.26.0`).

## Installation

```sh
go get github.com/chickinfry/chickinfry-go
```

## First call

```go
package main

import (
	"context"
	"errors"
	"fmt"

	chik "github.com/chickinfry/chickinfry-go"
)

func main() {
	transport, err := chik.NewHTTP("https://api.example.com")
	if err != nil {
		fmt.Println(err)
		return
	}

	var output struct {
		Status string `json:"status"`
	}
	err = transport.Invoke(context.Background(), "service.operation", map[string]string{}, &output)
	if err != nil {
		var operationErr *chik.OperationError
		if errors.As(err, &operationErr) {
			fmt.Println("operation failed:", operationErr.Code, operationErr.Status)
			return
		}
		fmt.Println(err)
		return
	}
	fmt.Println(output.Status)
}
```

`NewHTTP` accepts HTTPS origins or an explicit IP loopback HTTP origin such as
`http://127.0.0.1:8787`; other origins are rejected. `WithBearer` returns a copy
of the transport that sends a bearer token, and `WithSession` attaches a
`SessionStore` for automatic one-time refresh.
